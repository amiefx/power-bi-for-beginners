# Lesson 1.3 — Install Power BI Desktop

▶️ **Video:** <video link>

Power BI Desktop is free. Install it the right way, from the Microsoft Store, so it stays up to date and the course files always open.

## What you'll learn
- Why we install Power BI Desktop from the **Microsoft Store** (it updates itself every month, and you don't need admin rights)
- How to find the right app and check the publisher
- How to open Power BI and start a **blank report**
- How to check your version: **Help → About**

## What you need
- Windows 10 or later, 64-bit (Power BI Desktop doesn't run on a Mac: use a Windows PC or a Windows virtual machine)
- On a work computer, the Store can be blocked. Then ask your company.

## The steps in short
1. Open the **Microsoft Store** from the Start menu, and search for **Power BI Desktop**. Or use the direct link: https://aka.ms/pbidesktopstore
2. Check the publisher: it must be **Microsoft Corporation**, so you get the real app.
3. Click **Install** (some computers say **Get**). Wait until it's done; the button then says **Open**.
4. Click **Open**. The start screen appears. Click **Blank report**: an empty report, no data and no visuals yet.
5. You don't need an account to build reports. If you see a sign-in window, you can close it for now. You'll need an account to publish and share, later in the course.
6. Check your version: the **Help** tab (right after **Optimize**) → **About**. The **Version** line shows your version and the month and year of the release. Then click **Close**.
7. Older than the video's version? Update it in the Store: **Library** → **Get updates**.

⚠️ **Common mistake:** an old version from a website. Newer course files won't open in it. It's best to remove it first (**Settings** → **Apps** → **Power BI Desktop** → **Uninstall**; your report files stay), then install from the Store. If an app's name says **Report Server**, it's a different app: you can keep it, but get Power BI Desktop from the Store too.
