# Lesson 0.2 — How to follow this course

▶️ **Video:** <video link>

Every lesson builds on the course files. In this lesson you download them, set up one folder for the whole course, and open your first Power BI file. Then you learn how to turn on subtitles.

## What you'll learn
- What the **companion repo** is: the free course files on GitHub (data, Power BI files and challenge answers)
- How to download **data.zip** from **Releases** and extract it into `C:\PowerBI-Course`
- What a **checkpoint file** is, and how to read its name: `c01v05-end` = chapter 1, video 5, end of the video
- How to download a Power BI file from a lesson page and open it
- How to turn on subtitles, translate them, and slow the video down

## Files
| | File | Where |
|---|---|---|
| Data | `data.zip` (all the course data) | [Releases → data](https://github.com/amiefx/power-bi-for-beginners/releases/tag/data) → extract into `C:\PowerBI-Course\data\` |

| Start / End | none: this lesson doesn't change a Power BI file | — |

## The steps in short
1. Open the course files (the link is in the video description). Click **Releases**, then **data.zip**. Skip the "Source code" links: they're for programmers.
2. Click the **Code** tab, then **lessons** → **ch01-getting-started** → **c01v05-first-report**. Click **c01v05-end.pbix**, then **Download raw file** (the arrow at the top right). Your browser puts both files in your **Downloads** folder. If it asks, choose **Keep** or **Allow**.
3. Open File Explorer (Windows key + E) and your **Downloads** folder. Click `data.zip`, then Control-click `c01v05-end.pbix`, and press **Ctrl + X** to cut them.
4. Click **This PC**, then double-click your C drive (the one with C in its name). Right-click an empty spot, choose **New → Folder**, name it **PowerBI-Course** and press Enter. Open it and press **Ctrl + V**.
5. Right-click `data.zip` and choose **Extract All...**. Windows offers `C:\PowerBI-Course\data`. Keep it and click **Extract**.
6. Make one more folder the same way: **ch01**. Drag `c01v05-end.pbix` onto it, open the folder and double-click the file. Power BI Desktop opens the finished report. (No Power BI yet? Install it in lesson 1.3 first.)
7. Subtitles: click **CC** under the video, or press the letter **C**. Your own language: **Settings → Subtitles/CC → Auto-translate**. Too fast? **Settings → Playback speed**, or press **Shift + ,** (the comma key).

⚠️ **Common mistake:** opening a file while it's still inside the zip. Always extract the zip first.
